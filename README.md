# 字幕固定与去重叠（Cue Lock）

纪录片补录工具单页：锁定少数字幕起点并消除全部相邻重叠；顶层可切换到
**现场旁白采集**录音台。

## 求解模型

变量为每条字幕的整数起点 `x[i]`，约束：

- `earliest[i] ≤ x[i] ≤ latest[i]`；未导出的边界分别按 `0` 与
  `86_400_000` 处理（旧三字段文件即全天窗口）
- `x[i+1] ≥ x[i] + duration[i]`（相邻不重叠）
- 固定点 `x[cueIndex] = start` 精确命中

目标是最小化相对已采纳稿 `base[i]` 的绝对位移总和
`Σ |x[i] − base[i]|`；多解时取按 cue 顺序字典序最小的整数向量。

令前缀时长 `P[i] = Σ_{k<i} duration[k]`，`y[i] = x[i] − P[i]`、
`b[i] = base[i] − P[i]`，问题化为**带固定观测和逐点盒子的 L1 保序回归**：
`y` 单调不降，并满足
`earliest[i] − P[i] ≤ y[i] ≤ latest[i] − P[i]`。

- 求解器直接做**带界块 PAVA**：每个块维护下加权中位数，块拟合值为中位数
  相对本块下界最大值 / 上界最小值的投影；不会先求无窗口答案再逐项裁剪；
- 固定点以超过全部普通权重的权进入块内，保证块值钉死；
- 块内双半区用左倾堆（lower 最大堆 / upper 最小堆）维护，整体
  **O(n log n)**，20 000 项求解耗时远低于 2 秒；
- 先做无固定点窗口前向包络，再做固定点扫描，稳定区分：
  - `WINDOW_INFEASIBLE`：无固定点也违反窗口链；
  - `PIN_OUTSIDE_WINDOW`：固定点落在自身 raw `[earliest,latest]` 外；
  - `WINDOW_CHAIN_CONFLICT`：固定点自身在窗口内，但前序时长/固定点传递
    后越界。错误均返回最早冲突 cue、所需起点和允许上界。

## 页面流程

1. 导入 JSON：根对象仅含 `cues`，1–20000 项。每项必须含整数
   `start`（0–86400000 且严格递增）、`duration`（1–60000）、
   `text`（1–200 字符）；可独立添加整数 `earliest` 和/或 `latest`
   闭区间。旧三字段文件按全天窗口处理；越界、反序、额外字段会拒绝整份
   修改。非法导入显示 `INVALID_CUES`，清空预览并保留最近一次合法工作稿。
2. 行内可分别编辑每条 cue 的最早/最晚起点：清空表示恢复对应全天边界；
   非法整数或使区间反序的编辑不会修改快照。每条 cue 还可绑定一个整数
   固定起点；重复编辑覆盖旧值，清空/解除即删除。
3. 预览：显示新起点与逐行位移（带标记）；约束不可行时显示最早冲突并
   清空预览。此时可在提示旁**生成最大保留修复**：
   - 修复严格基于生成时的窗口快照；先传播窗口下界/上界，若窗口本身不可行，
     解除任何固定点都不能恢复，因此不生成方案并返回冲突位置；
   - 不在传播后盒子 `L[i] ≤ pinStart − P[i] ≤ R[i]` 内的固定点列为
     **必然解除**；其余固定点中求可共同满足（变换值非降）的最大基数集合
     （LNDS），最大集合并列时比较含必然解除项的完整 cueIndex 升序解除列表，
     取字典序最小者；
   - 预览只显示保留数与完整解除清单；分析是纯函数，不触碰 pins、基线或
     当前 `INFEASIBLE` 错误。求解层提供独立可测契约
     `analyzeMaxRetention(WithSpan)`，在 k 个固定点上为
     **O(k log k) 时间 / O(k) 空间**（两遍 tails + 成对堆），不通过逐次
     删除冲突点反复调用 solve 实现。
4. 采纳：预览结果成为下一轮基线（固定点保留，便于迭代）。
5. 修复方案携带生成时的工作稿、基线、窗口与固定点**修订身份**；应用时四者
   复核一致才一次性替换 pin Map 并重新求解，否则动作提示**已过期**且不产生
   任何部分修改。任何导入、采纳、窗口修改或固定点增删改都立即作废旧方案。
6. 下载：同结构 JSON（存在的 `earliest/latest` 保留；旧三字段输入继续输出
   三字段，采纳结果同样保留窗口）。

## 现场旁白采集

顶层「现场旁白采集」与字幕编辑互斥切换；录音台是完全独立的会话，**不读取
任何字幕数据**。切回字幕页即卸载录音台并幂等释放全部资源。

状态机：`请求授权 → 待录 → 录制 → 封装 → 复听`，复听可播放成品或
「废弃重来」（重新授权并开启递增会话号的新会话）。

- 权限与录制器**只在点击「启用麦克风」后**创建；初次渲染与 StrictMode
  重挂载（构造→销毁→再构造）不请求权限、不产生并行录制器；
- 所有媒体调用走可注入适配器 `NarrationMediaAdapter`（浏览器实现外可在
  Vitest 中注入伪适配器）；启用时先协商 `MediaRecorder` 支持的 MIME；
- 递增会话号绑定录制器、音频块与对象 URL；只有当前会话同时收到最终
  非空 `dataavailable` 与 `stop` 后才用非空块生成 take，迟到事件无法
  覆盖新 take；
- `AnalyserNode` 采样仅驱动输入电平条；时长取 `performance.now()`
  单调时钟差，后台限频只暂停刷新，不截断录音、不改变最终字节；
- 不支持录音、拒绝授权、无设备、音轨中断、启动/编码错误、封装失败、空
  数据均进入可恢复错误（重试 / 返回）；停止、切页与卸载幂等关闭音轨、
  音频图并撤销对象 URL。

## 开发

```bash
npm ci
npm run dev       # 开发服务器
npm run build     # tsc 类型检查 + Vite 构建
npm test          # Vitest（穷举核对 + 性能）
npm run verify    # build && vitest run（一次性验收命令）
```

测试用短序列（完整网格 + 随机 n≤3 窗口/固定点用例）与整数 DFS
穷举比对目标值和完整最优向量，覆盖窗口边界、偶数块下中位数平局、固定点
自身越窗与前序链冲突，并对 20 000 项的对抗模式断言 2 秒时限。最大保留修复
单独用 Vitest 穷举短序列的全部整数窗口和固定点子集，与 2^k 暴力解核对
保留数、完整解除清单、窗口闭包过滤、窗口自身不可行、平局裁决，覆盖变换值
`[5,1,4]`（解除首项）、改窗口或 pin 后应用旧方案无副作用（EXPIRED），
并以 20 000 个固定点的对抗序列验证 O(k log k) 时限与应用后必然可行。

## Docker Compose

```bash
WEB_PORT=8080 docker compose up web --build      # 发布页面
docker compose --profile verify run --rm verify  # 一次性验收服务
```

`WEB_PORT` 默认 8080。
